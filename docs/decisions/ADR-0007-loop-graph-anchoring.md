# ADR-0007: 自己改善をループのグラフとして設計し、接地アンカーで循環を防ぐ

- Status: Accepted
- Accepted: 2026-07-19 mryfmo 指示(ADR-0007/0008 の取り込み・RSI 追加・三軸統合と根本修正の指示)による。
- Context: 単一の自己改善ループには、(1) Goodhart の法則による指標と目的の乖離、(2) 参照値への上方盲目、(3) 独立に作られたループ間の衝突、(4) 監視者不在による測定自体の劣化、という 4 つの構造的失敗がある。成熟した自己改善は、ペアリング・階層・調停・監査を備えた「ループのグラフ」として扱う必要がある。ただし、グラフだけでは相互確認の循環に陥る。そこで、反論不能な接地測定、凍結ノード、機構の外から与えられる価値判断を「アンカー」として置く。出典はユーザー提供エッセイ（2026-07）であり、[Peter Steinberger のポスト](https://x.com/steipete/status/2078277297791189132) と[関連ポスト](https://x.com/IntuitMachine/status/2068808668393451770)に言及している。古典的系譜には Goodhart の法則、Argyris の double-loop learning、参照値を誰が持つかという制御階層を扱うサイバネティクスがある。
- Decision:
  1. **指標ペア必須。** 最適化ループの駆動指標を単独で使わない。スキル成功率と訂正率、起票数と誤起票率のように、対抗指標とのペアで定義する。[WORKPLAN v1.1](../plans/WORKPLAN-HARNESS-SELF-IMPROVEMENT-v1.1.md) P1-F2-T5 が作成する `docs/reference/metrics.md` は、すべての指標をペア構造で定義する。
  2. **参照値のオーナーと改訂ループ。** 昇格 N/M%、diff 40%、起票上限 5 など、すべての閾値と目標値にオーナー（mryfmo）と改訂周期を付ける。改訂自体も統治されたループとし、P1-F9-T4 を初回、その後は周期見直しとする。
  3. **ループ速度の分離と調停。** 夜間 GC・還流の速いループと、閾値・ADR 改訂の遅いループを分ける。Curator の追記と GC の削除、昇格時の汎化とプロジェクト特化が衝突した場合は、当事者ループ内で解決しない。上位の調停として orchestrator が提案し、mryfmo が決裁する。
  4. **アンカー分類と循環禁止。** 測定を、実行されたテスト・eval、人間のマージ・却下・訂正、実データ件数という「接地」と、集計統計、LLM 評価・ルーブリックという「派生」に分ける。派生指標だけで最適化・昇格・削除を決定してはならない。派生指標は、1 つ以上の接地指標とペアの場合に限って入力にできる。P1-F5-T6 の SkillCoach 型ルーブリック（LLM 評価）は、単独で F-OPT の入力にしない。
  5. **凍結ノードの明示。** 評価スイート定義、スキャン規則、凍結マニフェスト、本 ADR 群を、最適化ループが変更してはならない対象として列挙する。[既存の hash-freeze](../reference/evidence-and-gates.md) と NFR-01 で強制する。
  6. **接地監査。** P1-F8-T7 の月次監査に「循環検査」を含める。各最適化ループについて、直近周期の決定が接地指標に依拠したかを検証し、派生指標だけで回った決定を違反として報告する。
- Consequences: (+) Goodhart、循環的な自己確認、ループ間衝突を構造的に防御できる。設計済みの evidence、凍結、監査を使うため実装は薄い。(−) すべての指標にペアを求めるため、指標設計のコストが増える。ルーブリック単独の高速最適化はできない。これは意図した制約である。
- 根拠: ユーザー提供エッセイ（2026-07）と上記 2 ポスト、Goodhart の法則、Argyris の double-loop learning、サイバネティクス。[ADR-0003](ADR-0003-ace-knowledge-refinement.md) のデルタ更新、[ADR-0004](ADR-0004-fail-closed-pr-pipeline.md) の fail-closed、[ADR-0006](ADR-0006-skill-supply-chain-governance.md) の凍結・監査と整合する。P1-F4-T9 がすでに人間採択率と誤起票率のペアを規定しており、本原則の先行例になっている。
