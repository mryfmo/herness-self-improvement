# Goal

P1-F1-T7 の docs frontmatter 規約、相対Markdown link検査、テンプレート、CIを依存ゼロで実装し、失敗CI実証を残してPR経由でmainへマージする。

# Scope

task a009 の allowed filesに限り、`ci/check-docs.py`、`ci/test_check_docs.py`、`ci/docs-frontmatter-exempt.txt`、CIと凍結manifest、wiki規約、新規規約に不足する既存reference frontmatter、a009証跡を扱う。保護5 pathsの本文は変更しない。

# Assumptions

- frontmatter対象は `docs/**/*.md`、link対象は同文書とroot `README.md`。
- YAML dependencyを追加せず、先頭の区切り内にあるtop-level scalar 3 fieldsだけを標準ライブラリで検査する。
- 相対inline/image/reference-style Markdown linkのpath解決を検査し、fragmentだけ・URI scheme・HTTP(S)は対象外とする。
- WORKPLAN 2 versions、SPEC、REPORT、ADR bundleの5 pathsを4文書群としてfrontmatterだけ免除し、link検査は維持する。
- task指定が `python3 stdlib` のためuv/pre-commit/Makefileは追加しない。

# Design

checkerはrootを引数に取る単一`check()`へfrontmatterとlink検査を集約し、CLIはcurrent working directoryを使う。testはtemporary repository treeで正常、欠落、3形式不正、broken link、exemptionを直接検証する。CI fail実証は最終実装commitから一時branchへ不正文書1件だけを追加し、失敗run URL取得後にbranchを削除する。

# Tests

- 実装前にtestがchecker不在で失敗する。
- valid owner/date/freshness、relative link、HTTP linkがpassする。
- frontmatter欠落、empty/non-string owner、invalid/nonexistent date、invalid freshnessがfailする。
- missing/outside relative targetがfailする。
- exemptionはfrontmatterだけ免除し、exempt文書のbroken linkはfailする。
- 現行repository check、既存CI、hash verify、secret scan、PR CI、main CIを通す。
- 一時branchのmissing frontmatter + broken linkがpush CIでfailする。
