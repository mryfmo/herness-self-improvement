# Scope

# Assumptions

- evidence storeは既存append-only `hx_audit`を再利用し、新schemaは追加しない。
- evidence CLIは既存DBのみを受け付け、ホーム `.agents` 配下を拒否する。
- hash freezeのrootはcurrent working directory、manifest自身・`__pycache__`・`.pyc`は対象外とする。

- standalone Python scriptsはtask指定どおり`python3` stdlibで実行し、allowed外のuv/pre-commit構成は追加しない。

# Design

`hx-evidence.sh`はSQL quoteとJSON validation後、`hx_audit`へrecordし、list/traceはread-only表示する。`hash-freeze.py`は設定された4 path配下のregular filesをdeterministic SHA-256 manifestへfreeze/verifyし、差分pathを列挙する。`secret-scan.py`は`.git`とbinaryを除外し、既知prefix・bearer・key/value・JWT・private-key headerを検出する。3機能は単一shell testで実DB/実fileを用いて検証する。
